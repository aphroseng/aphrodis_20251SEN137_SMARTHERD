# Dataset Card: SmartHerd Livestock & Health Records

- **Source Link:** Sourced from public agricultural datasets (e.g., Kaggle Cattle & Livestock Health datasets adapted for educational database management).
- **Licence:** Open Educational Use / Public Domain.
- **Format:** Comma-Separated Values (CSV).
- **Size:** 500 records (simulated / structured for database development).
- **Date Collected:** October 2026.
- **What One Record Represents:** Each single row represents a specific livestock health check, including animal tag ID, species, breed, age, weight, health status, and the veterinarian who conducted the inspection.

## Data Quality Report (Initial Inspection):
- **Missing Dates:** 37 missing treatment/inspection dates.
- **Duplicate Rows:** 12 duplicate records found regarding routine check-ups.
- **Inconsistent Spelling:** 4 different spellings of farm locations/districts (e.g., "Nyarugeng", "Nyarugenge", "NYARUGENGE", "Nyarugeng'").
- **Data Type Issues:** Animal weights and prices/costs stored as plain text instead of numeric values.
- *Note:* As per project instructions, no data has been cleaned or modified yet; these issues will be resolved during data cleaning in Phase IV.
